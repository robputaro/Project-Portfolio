ROB PUTARO — SELECTED PRODUCT & SYSTEMS WORK  ·  REV 05

WHAT CHANGED IN THIS PASS
This is a design refinement aimed at making the site read as an
intentionally built portfolio rather than an AI-generated one.

Direction: "systems register / datasheet" — the documentation
aesthetic for a body of engineering work. Chosen because the work
itself is operating systems (scoring, queues, diagnostics, data),
and it reinforces the positioning: a builder, not just a creative.

Specific changes
- Typography: dropped Inter. Now Space Grotesk (display) + IBM Plex
  Sans (body) + IBM Plex Mono (all data/labels). Loaded via Google
  Fonts with system fallbacks.
- De-carded the layout: removed the rounded boxes, pills, soft
  shadows, hover-lift, dot-kicker badge, and floating "Actual
  working UI" pills. Structure is now hairline rules + a real grid.
- Palette: moved off warm cream + lime to a cooler drafting-paper,
  ink, and a single restrained blueprint-blue accent used only for
  marks and active states.
- Projects are now a numbered build index; screenshots are shown as
  Fig. plates on dark wells with mono captions.
- Supporting systems are a ledger, now with real UI for all three:
  revenue-opportunity-suite, clinic-intelligence-engine (added), and
  an updated conveyor-strategy-os board shot.
- Approach uses a real numbered process; capabilities are a mono
  spec matrix. Footer is a colophon.
- Case-study modal restyled as a datasheet (Problem / Build / Role /
  Outcome). All original case-study copy is preserved.
- Accessibility: keyboard focus rings, prefers-reduced-motion
  respected, responsive down to mobile.

BEFORE SHARING PUBLICLY
Scrub any client-specific names or internal data that should stay
private (there's a note to this effect on the page).
